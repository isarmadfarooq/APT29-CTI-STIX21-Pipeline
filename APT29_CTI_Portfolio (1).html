Overview

This project implements a fully automated Cyber Threat Intelligence (CTI) extraction pipeline in Google Colab. It processes the APT29 "Cozy Bear" CTI report (Operation PHANTOM BEAR) through a multi-stage pipeline: raw PDF ingestion → text extraction → LLM-based entity extraction → STIX 2.1 structured output → JSON bundle export and graph visualization.

The system leverages GPT-4o with carefully engineered system prompts to perform Named Entity Recognition (NER) on unstructured threat intelligence text, identifying threat actors, malware families, network indicators, MITRE ATT&CK techniques, vulnerabilities, and relationships between entities. All extracted data is mapped to the STIX 2.1 standard and serialized as an interoperable JSON bundle.

LLM Prompt Engineering

The extraction pipeline uses a structured two-layer prompt design — a system prompt that establishes GPT-4o as a CTI expert analyst, and a user prompt that passes cleaned text chunks with explicit JSON schema requirements:

system promptYou are an expert Cyber Threat Intelligence (CTI) analyst.

Your task is to extract structured entities from the given 
threat intelligence report text.

Extract the following entity types:
  - threat_actors: name, aliases, description, motivation
  - malware:       name, type, description, capabilities
  - indicators:    type [ip/domain/hash/url], value, context
  - attack_patterns: name, mitre_id, description, phase
  - vulnerabilities: cve_id, description, cvss, product
  - relationships: source, target, relationship_type
  - infrastructure: name, type, description

Return ONLY a valid JSON object matching this exact schema.
No preamble, no markdown, no explanation.
⚠
Text Chunking: The CTI report was split into 12,000-character chunks before LLM processing to respect GPT-4o context window limits. Results from all chunks were merged via a de-duplication function before STIX mapping.
